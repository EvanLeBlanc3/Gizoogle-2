# Gizoogle 2 — Tha Tranzizzle Machizzle

## Put it on GitHub Pages
1. Create a new public repo (e.g., `gizoogle2`).
2. Upload everything in this folder (keep the `icons` folder intact) to the repo root.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. Wait ~1 minute, then open `https://<your-username>.github.io/gizoogle2/`.

## Install on iPhone
1. Open the link in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Launch from the Home Screen icon. Open it once while online so it caches for offline use.

## Updating later
Bump `CACHE` in `sw.js` (e.g., `gizoogle2-v2`) whenever you change files, so phones grab the new version.
